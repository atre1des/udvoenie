# Удвоение

30-дневное упражнение для размышления о деньгах. Первый прототип приложения на русском языке.

## Запуск

Установите Node.js 20 или новее и выполните `npm start`. Откройте <http://localhost:3000>. Зависимостей для установки нет. Для размещения используйте папку `public/` на HTTPS-хостинге. Установка PWA и автономный запуск после первого посещения зависят от поддержки браузера.

## Что работает

- Путь от 1 000 до 536 870 912 000 USD или EUR с подсказками и необязательными вопросами для рефлексии.
- Выбор местной валюты с примерными фиксированными курсами из HTML-прототипа.
- Свободный темп прохождения, сохранение черновика, ответов и дневника в хранилище браузера.
- Итоги на 7, 14 и 30-й день с вопросами для самостоятельного подведения итогов и печатью дневника в PDF через браузер.
- Экспорт данных в JSON, удаление локальных данных и независимый калькулятор удвоения.
- Адаптивная вёрстка, тема устройства и автономное открытие после загрузки приложения.

## Следующий этап

Подключить серверное хранение с учётными записями и механизмами согласия, обновляемые курсы, диктовку и серверный Claude API. Первый прототип задаёт заранее написанные вопросы. Он не генерирует психологический разбор или портрет, не распознаёт кризисные сообщения и не подходит для консультирования.

Перед запуском согласовать рынки, языки, темп игры, платный доступ, обработку данных внешними сервисами и тексты кризисного сценария. Данные этого прототипа хранятся в текущем профиле браузера и могут быть прочитаны любым, у кого есть к нему доступ. Приложение не отправляет записи на сервер.

Кабинет коуча, совместная игра и нативные приложения остаются следующими возможными этапами после проверки спроса.
